## A.0.2 Colimits

Some constructive metatheories, such as Martin-Löf type theory, do not assume the existence of general quotients. The small object arguments are colimit constructions, so superficially would seem to be inapplicable in these contexts. Even if we only assume **Set** has coproducts, however, we can use them to construct some additional colimits, in particular cobase changes along *complemented* monomorphisms and colimits of $\omega$-chains of the same (see Example 2.3.4). As a corollary, the class of *levelwise complemented* monos in any presheaf category $\mathrm{PSh}(\mathcal{C})$ forms an $\omega$-backdrop. Thus, if a category of generators $u: \mathcal{J} \rightarrow \mathrm{PSh}(\mathcal{C})^{-}$ admits a density comonad $D_u$ satisfying enough decidability assumptions, then it generates an AWFS even in this weak setting. In Section 4.1, we give conditions under which uniform box-filling fibration AWFS's can be constructed with this backdrop. As with ordinals, parameterizing by a backdrop allows us to prove our results constructively without restricting their applicability for the classical mathematician.

The fact that we do not need general colimits in the metatheory is particularly interesting because these AWFS's can be used to interpret type theories that *do* have colimits in the form of higher inductive types [CHM18; CH19]. We see this as a higher analogue of setoid model constructions, which also interpret type theories with quotients in type theories without quotients [Hof97; ABKT19]; compare also Gambino et al.'s effective model structure on simplicial objects in a countably lextensive category [GHSS22].
