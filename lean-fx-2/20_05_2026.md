## 0. The meta-principle: replace the axiom with a reduction rule

Lean 4's standard library exposes three axioms — `propext`,
`Quot.sound`, `Classical.choice`. FX's discipline (CLAUDE.md) bans all
three plus `sorry`/`admit`/`noncomputable`/`@[extern]`/hypothesis-as-
postulate. The trust root must be *unconditionally* sound: an axiom in
the root contaminates everything downstream.

The escape hatch FX already exploits: FX is a **deeply-embedded object
theory**. Lean is the metalanguage; FX's reduction relation
`Step : Term → Term → Prop` is an ordinary inductive (zero axiom). So
any equality one would classically *postulate* can instead be made a
**definitional computation rule** on `Step`:

```
-- NOT: axiom Univalence : ...
-- INSTEAD (shipped, #print axioms = clean):
Step.eqType : Step (Ty.id (Ty.universe l) A B) (Ty.equiv A B)
theorem Univalence (l) (A B : Ty l n) :
    Conv (Ty.id (Ty.universe l) A B) (Ty.equiv A B) :=
  Conv.fromStep Step.eqType
```

**Principle (apply everywhere below).** A feature `F` that classically
needs axiom α partitions into two cases:

1. **Computational axiom** (univalence, funext, HIT eliminator
   computation, quotient soundness): α is an axiom *only because the
   traditional kernel lacked the reduction rule*. Add the `Step`
   constructor that computes α's content, then pay the cascade
   (confluence + SN + subject-reduction preservation). Result is a
   theorem, zero axioms. Cost is honest LoC, not a postulate.
2. **Non-computational principle** (choice, LEM, global well-ordering):
   no reduction rule recovers it; it is *independent* of computational
   foundations. A computational trust root should reject these — they
   are exactly the "if you can't prove it zero-axiom it's bullshit"
   class, and rejecting them is correct.

There is no third class where you are genuinely stuck needing a real
axiom for something you actually want. Every cake below is in class 1
(or is reframed into class 1).

## 1. Polarization — Cubical ∂CBPV  📋⚠️  (~12.5K LoC validated)

**Concept.** Split the type universe into **positive** (value, `+`) and
**negative** (computation, `-`) polarities (Levy CBPV 2001). Positive
types are defined by their *introduction* rules (data; inductives, Σ,
sums, `nat`, `bool`); eliminated by pattern match (ι-rules fire here).
Negative types are defined by their *elimination* rules (codata; Π, `&`
lazy products, codata, session); β-rules fire here. The two universes
are mediated by an adjunction:

```
F ⊣ U
F : ValType → CompType    -- "returner"  (produce a value; monadic F∘U)
U : CompType → ValType    -- "thunk"     (suspend a computation; comonadic U∘F)
```

CBV and CBN are both decompositions into CBPV; this fixes evaluation
order definitionally — "a value *is*, a computation *does*."

**Design hypothesis (verify, do not assume).** FX's modal chain
`♭ ⊣ ◇ ⊣ □ ⊣ ♯` already supplies adjoint structure of the right shape:
the comonadic `□`/`♭` aligns with `U∘F`, the monadic `◇`/`♯` with
`F∘U`. If the alignment holds, the U/F connectives are *definable*
rather than new primitives. (Validation did not confirm this; budget
the full split.)

**Fire Triangle (Pédrot–Tabareau, POPL 2020).** Substitution +
dependent elimination + effects cannot all be unrestricted (no-go
theorem). ∂CBPV resolves it: CBN restricts dependent elimination, CBV
restricts substitution. **The hypothesized 4th corner:** restrict the
*motive* to positive types and you may keep full subst + full effects +
restricted-positive dependent elimination. FX's K07 dependent-motive
refactor (#1516–#1523) is the live test of this corner — natElim/listElim/
idJ motives moving to `Ty level (scope+1)` is exactly the discipline
that could thread the needle.

**Novel slice.** Cubical + polarization has no published combination.
Cubical MTT exists (modal+cubical); ∂CBPV exists (polarized+dependent+
effects); the *cubical ∂CBPV* intersection is open. FX is positioned to
be first.

**Implementation path.**
- `Foundation/Polarity.lean`: `inductive Polarity | pos | neg`.
- Tag each `Ty` ctor with polarity; tag each `Term` ctor by its result
  polarity; add `U`/`F` coercions (or derive from `□`/`◇` if hypothesis
  holds).
- Polarize `Step`: ι on positive heads, β on negative heads, commuting
  conversions where polarity flips.
- Cascade tax: every cd-arm and Compat lemma gets a polarity tag.
  Validated ≈ **12.5K LoC** (5× my earlier estimate; the cascade
  dominates).
- **Payoff:** makes the NbE quote (§9) a one-page polarity-directed
  η-expansion (Abel–Sattler 2019), and gives the ∂CBPV dependent-effect
  story (§4).

**Apex of:** Levy CBPV 2001 · Pédrot–Tabareau ∂CBPV 2020 · Aagaard–
Kristensen–Gratzer–Birkedal Cubical MTT 2024.

## 2. Guarded recursion + partial types — the `▷` modality  📋  (~2–3K LoC, zero-axiom)

**This is the load-bearing item.** It unifies three topics that looked
separate: partial types, the "drop SN" nuclear option, and the
probabilistic-effects foundation.

**Concept.** Add a *later* modality with guarded fixpoints:

```
▷ : Type → Type                       -- "available one logical tick later"
next : A → ▷ A
löb  : (▷ A → A) → A                  -- guarded fixpoint
-- reduction:  löb f  ⟶  f (next (löb f))     (Step rule, zero-axiom)
```

Productivity replaces termination: every recursive self-reference must
sit under a `▷`, so each unfolding is guarded by exactly one tick. This
is **SN-preserving** — there is no infinite *unguarded* reduction.
Clock quantification recovers genuine coinduction:

```
∀ κ. A                                -- clock-quantified type
force : (∀ κ. ▷ A) ≅ (∀ κ. A)         -- Atkey–McBride elimination
```

**Capretta Delay as a guarded fixpoint.** The partiality monad is
definable, not primitive:

```
Delay A := νX. A + ▷ X                 -- coinductive (guarded)
now   : A → Delay A
later : ▷ (Delay A) → Delay A
⊥     := later (next ⊥)                -- the divergent value, well-defined
```

`Delay` is a monad; `now x >>= f = f x` holds *definitionally* (no
`Quot.sound`).

**Resolving "drop SN" without dropping SN (♻️ de-quarantined).** The
nuclear "first-class non-termination" option becomes:

- **Evaluator goes coinductive:** `eval : Term → Delay Value` via
  guarded recursion. **Total and zero-axiom** — divergent terms produce
  infinite `later` chains, which are legitimate coinductive inhabitants.
- **Conversion goes semi-decidable on the partial fragment:**
  `Conv⊳ : Term → Term → Delay Bool`. Run it; it answers if it
  converges. This is *not a loss* — surrendering termination on a
  fragment *must* surrender decidability on that fragment; the two are
  the same coin.
- **The membrane is the modality, not a hand-drawn barrier.** Pure
  fragment: SN, `eval : Term → Value` total, `Conv : Bool` decidable.
  Partial fragment: under `▷`, `eval : ▷Term → Delay Value`,
  `Conv⊳ : Delay Bool`. You cannot extract `▷A → A` without a clock
  quantifier `∀κ`, sound only when the computation terminates. The bi-
  universe the user wanted is exactly this modal stratification.

**Correction (validated).** FX's existing clock-domain dimension
(§18.7, `Graded/Instances/ClockDomain.lean`, a `List String` row of
hardware clock labels) is **NOT** Nakano's `▷`. Same word, different
math (Bizjak–Møgelberg 2015 use logical time-stream clocks). So `▷` is a
**new** modality, hosted by the MTT mode 2-category (§6), not a
reinterpretation of clock domains.

**Implementation path.**
- New `Ty.later`, `Term.next`, `Term.lobFix`; `Step.betaLob`.
- Guardedness check enforcing `▷`-guarded self-reference (load-bearing
  for SN — without it the M04 chain breaks).
- `Codata/Delay.lean` building `Delay` as a guarded ν-type; needs the
  K08 codata-β rule (`Step.betaCodataDest`) unblocked first.
- Clock quantification `∀κ` + `force`.
- Validated ≈ **2–3K LoC** total; Capretta-Delay sub-part ≈ 800–1500
  LoC. No published Lean-4 Capretta formalization exists — novel.

**Apex of:** Nakano 2000 · Atkey–McBride ICFP 2013 · Capretta 2005 ·
Møgelberg–Zwart clocked-cubical 2025 · Stassen–Møgelberg–Zwart–Aguirre–
Birkedal POPL 2025 (the probabilistic extension drops in once `▷` +
finite-distribution HITs land).

## 2.5 Concurrent separation logic via grades + `▷`  📋  (zero-axiom; smaller than first estimated — see §2.7)

**Concept.** Separation logic and partial types are *orthogonal* axes
sharing one foundation. Separation = spatial (ownership, framing,
disjointness); partiality = temporal (divergence). FX already owns the
spatial half: the usage/permission grade IS separation logic (§6.4 —
"separating conjunction `*` = `+` of the grade algebra; permission PCM
`Frac/Zero/Omega`; Frame rule automatic"). The missing piece is the
concurrency layer, whose one new foundational dependency is `▷` (§2).

**Why `▷` is the bridge.** Modern concurrent SL = Iris (Jung–Krebbers–
Birkedal–Dreyer, JFP 2018), on three pillars: (1) cameras / resource
algebras (PCMs) for ghost state; (2) impredicative invariants `inv N P`;
(3) **step-indexing via `▷` + Löb** to make (2) well-founded. Pillar (3)
is literally Nakano's `▷` from §2 — the guarded-recursion work for
partial types is the same stone Iris stands on.

    Iris camera          ≅  FX grade dimension / PCM (§6.5)        ✅ shipped
    Iris `▷` later        ≅  FX `▷` (§2)                            📋 §2
    Iris invariant `inv`  ≅  2-cell preserved across atomic 1-cell  📋 (see §2.7)

**Do NOT embed Iris.** FX bakes separation into the *type system*
(grades), not a separate assertion logic. Native integration = three
pieces, all on `▷`:

1. **Impredicative invariants on `▷`.** `Ty.invariant` storing a guarded
   grade-predicate `▷ SLProp` (`SLProp` = a constraint on the permission
   dimension, NOT a new type). Opening it around an atomic step is a
   `Step` rule; impredicativity is sound because the content is
   `▷`-guarded (Löb breaks circularity).
2. **Atomic steps + invariant opening.** `Atomic` effect on physically-
   atomic ops (FX §13.10 already ships `lock_free`/CAS, §11.10 memory
   ordering); rule "open invariant `i` for one atomic step."
3. **`par` as footprint disjointness.** `par(f,g)` typechecks iff
   `footprint(f) + footprint(g)` has no CONFLICT in the permission
   semiring — exactly §6.4's `Frac(p)+Frac(q)=CONFLICT when p+q>1`. The
   automatic frame rule becomes the parallel rule for free.

**Reference target — F* Pulse / PulseCore** (Swamy et al., MSR ~2024):
embedded DSL for *partial, impredicative concurrent SL*. Computation
type `stt a pre post` (Hoare triple AS a type); `pts_to r #p v`
fractional points-to; PCM ghost state; `inv` invariants opened with
`with_invariants`; `par` (soundness = footprint disjointness via `**`);
partial correctness (divergence allowed); extracts to C/OCaml. Pulse
*bundles* separation + state + partiality into one monad; **FX factors
them** — partiality is the `▷`/`Delay` axis (§2), separation the grade
axis (§6.4), composing because both are modal layers over one kernel.

**Apex of:** O'Hearn CSL 2004 · Brookes CSL semantics 2007 · Jung et al.
Iris JFP 2018 · Swamy et al. Steel / Pulse / PulseCore.

## 2.6 Nuclear permissions: discardable tree-shares + cameras  📋  (carrier swap + library, zero-axiom)

**The nuclear move is not "more fractions" — it is replacing the
rational fraction with the right algebra.** Rational fractions
`p ∈ ℚ∩(0,1]` (Boyland 2003, what FX ships) are broken three ways:

- **Infinite divisibility** — always halvable ⇒ no indivisible *token*
  ("exactly one holder, un-splittable").
- **No usable complement** — "the rest of `p`" is `1−p`, just another
  rational; doesn't compose with structured / nested ownership.
- **Over-identification** — a `½` from splitting `1` is
  indistinguishable from a `½` obtained otherwise.

**Nuclear ladder (each rung fixes the one below):**

    0. rational fractions ℚ∩(0,1]               Boyland 2003          ← FX now
    1. counting permissions (count + source)    Bornat et al. 2005
    2. TREE SHARES — free Boolean algebra        Dockins–Hobor–Appel '09  ★ the fix
    3. discardable fractions dfrac = Frac ⊎ Persistent   (Iris)
    4. arbitrary cameras / resource algebras     Iris JFP 2018          ★ the generalization
    5. dependent / value-indexed shares          QTT grade-as-term      (frontier)

**Rung 2 — tree shares (the fix).** Elements of the *free Boolean
algebra* on a countable set (finite binary trees, leaves ∈ {⊤,⊥}).
Unlike ℚ they have: a genuine **complement** `∁s` (the exact "rest",
composing with structured ownership); **both** continuous fractional
sharing AND discrete token accounting in one algebra; a **decidable**
equational theory (grade-checker discharges share goals automatically);
canonical **disjointness** `s₁•s₂` defined iff `s₁⊓s₂=⊥`. This is what
VST uses instead of ℚ.

**Rung 3 — dfrac.** Carrier `Frac(q) ⊎ Discarded`: permanently discard
write capability to gain a **persistent** (∞-duplicable, read-forever)
permission. Immutable-after-init data becomes first-class.

**Rung 4 — cameras.** Permission = any user PCM with frame-preserving
updates: fractional, tree-share, counting, dfrac, the authoritative
camera `●a ⊎ ◯b` (one owner-of-truth + many fragments), STS cameras
(ownership = protocol state) — all instances.

**Single most nuclear pick:**

> Permission = element of an arbitrary user-defined camera, default
> carrier = **discardable tree-shares** (Boolean shares ⊎ persistent),
> share allowed to be a **dependent term**.

**FX integration (mostly a carrier swap).** FX's permission dimension is
already "Rung 4 with carrier = ℚ" — a graded PCM dimension, and §6.5
`grade_dimension` already admits arbitrary user-PCMs (= cameras). So:
(a) swap default carrier ℚ → tree shares, reproving laws (decidable ⇒
SMT-dischargeable), remapping `own=⊤ / ref=s<⊤ / ref mut=⊤-exclusive /
ghost=⊥`; (b) add the dfrac discarded element; (c) cameras come free via
`grade_dimension`; (d) defer dependent shares to §6.7. FX accidentally
built Iris's camera framework as its grade-dimension mechanism — nobody
pointed the permission dimension at tree shares yet.

**Concurrency tie-in.** Tree shares are *specifically* what §2.5 needs:
the complement `∁s` is the clean thread-local-vs-shared split, so `par`'s
footprint-disjointness is a decidable tree-share `⊓=⊥` test; the
authoritative camera is the "one writer-of-record, many observers"
pattern; dfrac persistence is zero-accounting cross-thread immutable
sharing; dependent shares express "worker owns 1/n of the array."

**Socket tie-in.** Share/permission algebras are quantales → one more
instance of the §3 socket; the *carrier choice* (tree-share vs rational
vs camera) is where the nuclear-ness lives.

**Zero-axiom:** ✅ — decidable Boolean algebra + lattice + PCM, all
SMT-verifiable by the shipped grade-dimension machinery.

**Apex of:** Boyland 2003 · Bornat–Calcagno–O'Hearn–Parkinson 2005 ·
Dockins–Hobor–Appel APLAS 2009 (tree shares) · Iris cameras + dfrac.

## 2.7 Concurrency & permissions as (∞,∞)-polygraph structure — the conceptual roof  📋⚠️  (frontier)

**Headline.** K11.5 (horizontal composition) and K11.6 (interchange /
Eckmann–Hilton, **already shipped**) are — at the level of the rewriting
polygraph — the **separating conjunction** and the **frame rule** of
concurrent separation logic. FX has mechanized the structural core of
CSL and mislabeled it as category theory. §2.5 and §2.6 are concrete
instances *under* this roof.

**Setting.** K11 presents FX's rewriting as a polygraph = free strict
ω-category = an **(∞,∞)-category** (directed cells at every dimension, vs
(∞,1) where >dim-1 is invertible): dim 0 = `RawPolyTerm` (terms), dim 1 =
`Step` (rewrites, directed), dim 2 = `cd_lemma` (confluence), dim 3 =
Squier / Mac Lane (coherence, K11.18/19). Overlay separation:

**Four identities.**

1. **`*` = horizontal composition (K11.5); frame rule = interchange law
   (K11.6, ✅).** A 1-cell `c` with footprint `F`, horizontally composed
   with `id_R` on disjoint `R`, is governed by interchange
   `(a∘₀b);(c∘₀d) = (a;c)∘₀(b;d)` — exactly "doing `c` here commutes with
   untouched context." Disjointness of footprints = definedness of
   horizontal composition.

2. **Concurrency = independent (disjoint-footprint) 1-cells; Squier
   coherence = its soundness.** Disjoint rewrites compose freely
   (interchange); overlapping rewrites form critical pairs filled by
   coherence 3-cells. That partition IS the Mazurkiewicz independence
   relation / asynchronous transition system / higher-dimensional
   automaton (Pratt 1991, van Glabbeek; Goubault directed topology). So
   **K11.18 Squier coherence = the proof that FX's concurrency model is
   sound.** (Mimram — Polygraphs-textbook coauthor — works exactly the
   polygraph ↔ concurrency seam.)

3. **Fractional/tree-share permission = cell subdivision (research
   lead).** Tree shares = free Boolean algebra = finite binary trees;
   iterated binary subdivision (`Sd`) of an n-cell is itself a binary
   tree of sub-cells. *Conjecture:* the tree-share Boolean algebra ≅ the
   algebra of binary subdivisions of a cell; owning share `s` = owning
   the sub-region selected by `s`; complement `∁s` = the rest of the
   subdivided cell — the complement separation logic always wanted.
   `par` = two threads owning complementary subdivisions. Cleanest in
   precubical (HDA) cells; FX's globular polygraph needs the globular↔
   cubical bridge (Brown–Higgins / Al-Agl–Brown–Steiner; directed case
   subtler). Novel if it holds.

4. **`▷` = directed-step shift; invariant = preserved 2-cell.** A "tick"
   is a dim-1 cell; `▷A` = "A across a dim-1 boundary." Löb fixpoint =
   ω-limit of the cell tower along the directed 1-axis (passage to the
   limit-completion of the free ω-category). An Iris invariant opened
   around an atomic step = a 2-cell witnessing `P`'s sub-cell is
   preserved by the atomic 1-cell. Cameras = the operad of multi-port
   horizontal composition (K11.5's "multi-port arity").

**Unification table.**

| separation/concurrency notion | (∞,∞)-polygraph structure | FX status |
|---|---|---|
| separating conjunction `*` | horizontal composition (K11.5) | ✅ shipped |
| frame rule | interchange law (K11.6) | ✅ shipped |
| `par` / concurrency | independent disjoint-footprint 1-cells | needs naming |
| concurrency soundness | Squier coherence (K11.18) | pending |
| fractional/tree-share permission | binary subdivision of a cell | 📋 novel |
| `▷` later | directed-step shift / ω-limit completion | 📋 §2 |
| Iris invariant | 2-cell preserved across atomic 1-cell | 📋 |
| camera / resource algebra | operad of multi-port horizontal comp | ✅ (grade PCMs) |
| cost model (tropical §8) | cell weights; parallel work = free interchange | 📋 §8 |

So **concurrency, cost (§8), confluence (§8), and separation are all the
higher-dimensional structure of one polygraph.** Optimal *parallel*
reduction = shortest path in the tropical-weighted (∞,∞)-category where
horizontal composition of disjoint cells is cost-free — §8's tropical
reduction and the concurrency model are the same theorem.

**Caveats (honest).**
- **Globular vs cubical:** `PolyCell` is globular (source/target); HDA +
  tree-share-as-subdivision are cleanest precubical. Identity #3 needs a
  globular↔cubical bridge (groupoidal case known; directed (∞,∞) subtler)
  — research lead, not drop-in.
- **Prop→Type wall (validated):** `PolyCell` is `Type`; interchange-
  soundness is `Prop`. Structure (composition/subdivision/cost) is
  Type-side and reusable; the frame-rule *proof* stays Prop-side — you
  reuse K11.6's theorem, you don't skip it.
- **(∞,∞) directed type theory is frontier:** Riehl–Shulman / Weaver–
  Licata do (∞,1); a genuine directed-all-the-way internal TT with
  concurrency/separation internalized is open research. FX here would be
  at the edge of the known.

**Apex of:** Pratt HDA 1991 · van Glabbeek HDA · Fajstrup–Goubault–Raussen
directed algebraic topology of concurrency · Mazurkiewicz traces ·
Meseguer–Montanari *Petri nets are monoids* · Mimram polygraphs ↔
concurrency · Ara–Burroni et al. Polygraphs textbook 2023.

## 3. Quantale-unified dimensions — the universal quantitative socket  📋  (~20–30K LoC refactor, zero-axiom)

**Concept.** A **quantale** `(Q, ⊗, 1, ⋁)` is a complete lattice with an
associative product distributing over arbitrary joins. The graded
typing judgement carries a grade vector and the application rule is the
Atkey/McBride/Wood–Atkey rule:

```
Γ ⊢_{p1} f : (x :_r A) → B      Γ ⊢_{p2} a : A
------------------------------------------------------
Γ ⊢_{p1 + r · p2} f a : B[a/x]
```

with the Wood–Atkey 2022 *context division* `G/p` correction to the Lam
rule (`1/ω = 0` etc.) — FX already ships this corrected rule.

**Validated structure of the 21 dimensions.** (Not 22 — Staleness is
not a separate dimension per `Graded/Dimensions21.lean`.) Of the 21,
**17 are quantale-shaped** (semirings/lattices). **4 are outliers:**

| Outlier | Why it is not a quantale |
|---------|--------------------------|
| Type | not graded — bidirectional checking |
| Refinement | SMT predicate, not a grade |
| Protocol | typestate *sequence* — directed graph, no join |
| Version | lattice with adapter edges — distributivity breaks |

**Unification.** Collapse the 17 into ONE parametric core
`GradedModal Q` (parametric over the quantale), plus an adapter layer
for the 4 outliers. §6.8's cross-dimension collision catalog becomes
quantale-tensor non-commutativity computations rather than 23
hand-listed exceptions (those that are cross-tier — e.g. classified ×
async — stay as documented interactions because they cross the
quantale/typestate boundary).

**The socket (this is the "powerful under one roof" payoff).** Any
quantitative type system whose grades form a quantale plugs in as an
`instance` at ~400–600 LoC with **zero metatheory cost** (the graded
framework already proves Lam-soundness for any new quantale; the
`AtkeyAttack.lean` regression test is the gate). The validated
plug-ins:

- **Differential privacy** (Fuzz/DFuzz): sensitivity `s ∈ [0,∞]`,
  quantale `([0,∞], +, 0, ≤)`; sequential composition adds ε. Reed–
  Pierce 2010, Gaboardi et al. 2013. No dependent kernel hosts DP.
- **Quantitative information flow** (Smith 2009 min-entropy): leakage
  bound in bits; `declassify` spends a budget. Upgrades the existing
  binary Security dimension to quantitative; pairs with `with CT` for
  side-channel bounds.
- **Cost-as-coeffect** (decalf, POPL 2024): cost `c ∈ ℕ∪{∞}` via a
  `step_c` primitive, monoid `(ℕ,+,0)`, *directed* equality `≤`. The
  shipped `ComplexityGrade` semiring is the carrier; the work is
  threading it through App/Lam/Let (and a `ConvOrLeq` directed
  relation).
- **Capability**: capability-set lattice `(P(Caps), ∪, ∅, ⊆)`;
  `Modal/Cap.lean` is a 53-line stub awaiting this.
- **Gradual grades** (Siek–Taha gradual guarantee): grade `?` deferred
  to runtime contracts — the principled version of sketch mode (§22).

**Implementation path.**
- `Graded/Quantale.lean`: the `Q` interface + Lam-soundness once,
  parametrically.
- Migrate the 17 quantale dimensions to instances; keep the 4 outliers
  in a separate `Graded/Outliers/` adapter.
- Each socket plug-in is one `Graded/Instances/<Name>.lean`.
- Validated ≈ 20–30K LoC for the core refactor; each plug-in ≈ 500 LoC.

**Apex of:** Atkey–McBride QTT 2018 · Wood–Atkey 2022 · Moon–Eades–
Orchard GrTT 2021 · Abel–Danielsson–Eriksson graded MLTT (Agda) 2023 ·
Hanukaev–Eades adjoint-modes 2023 · the entire quantitative-types
literature, hosted in one kernel.

## 4. Dependent effect handlers via ∂CBPV  📋  (~6–8K LoC)

**Concept.** With polarization (§1) in place, algebraic effects are the
universal-property side of negative-type structure: operations are
negative-type "demands," handlers are observers responding per
operation. A *dependent* handler has return type varying with the
operation row.

**Fire-Triangle navigation.** Pédrot–Tabareau's ∂CBPV is the principled
foundation (vs Koka row-polymorphism or Eff HM-inference). The
restricted-positive-motive corner (§1) is what permits handlers +
dependent elimination + substitution together.

**Status (validated).** `Effects/Handlers.lean` ships only *row-level*
`HandlerCase` + `Handles` (no `Term.effectHandle` ctor, no continuation
semantics). `Effects/Foundation.lean` defers the `Ty.effect` row schema
+ `effectHandle` β-rules. So this is real kernel work: a new
`Term.effectHandle` ctor + β-rules + the D2.5-style cascade (each such

## 6. MTT-parametric multimodal core  📋  (~8K LoC + STT prereqs)

shipped `♭ ⊣ ◇ ⊣ □ ⊣ ♯` chain becomes a specific mode theory; reframing

**Status (validated, corrected).** FX's `Modality` is a *closed 5-ctor

## 8. Polygraph-native presentation + optimal reduction  🔨  (~3–5K LoC, zero-axiom)

**Concept.** An n-polygraph (Burroni 1993) presents an n-category by
generators in each dimension; `PolyCell : ℕ → Type` is shipped (K11).
Reductions are 1-cells, confluence proofs are 2-cells, coherences are
3-cells. **Squier's theorem:** a convergent (terminating + confluent)
rewriting system extends to a *coherent* presentation by filling
critical pairs with 3-cells.

**Validated boundary — the Prop→Type wall.** K11.16 is a *label
bijection* on the ~110 Step generators; K11.17 `cd_lemma.toDim2Cell` is
a *one-way embedding*. `RawStep.par.cd_lemma` is `Prop`-valued; `PolyCell`
is `Type`-valued. **You cannot extract a confluence proof from a cell**
(Prop→Type elimination wall). Therefore the earlier "polygraph derives
confluence, deletes 45K LoC" claim is **refuted** — and the confluence
cascade is only ~8.3K LoC anyway (not 50K). The polygraph layer is a
*labeling + cost discipline*, not a proof substrate.

**What the polygraph DOES give (Type-side, zero-axiom):**
- **Squier coherence** (K11.18) + **Mac Lane pentagon** (K11.19) as
  genuine theorems — first Lean polygraph mechanization (no Lean/Coq
  precedent, validated).
- **Cost-tropical optimal reduction.** Weight each generator cell by its
  cost grade; the tropical semiring `(ℝ∪{∞}, min, +)` turns "cheapest
  reduction path" into shortest-path over cells (Lévy optimal reduction
  + Burroni). This stays entirely Type-side, so it sidesteps the
  Prop→Type wall: cost is *data*, not proof. K11.19's planned
  "cost-tropical semiring" is exactly this.

**Apex of:** Burroni 1993 · Squier 1994 · Ara–Burroni–Guiraud–Malbos–
Métayer–Mimram textbook (Cambridge 2023) · Lévy optimal reduction 1978.

## 8.5 Trees are the 0-skeleton — the polygraph is the primary structure  📋  (architectural principle, zero-axiom)

**Thesis (sharpened).** A tree — FX's `RawTerm` inductive — is the
**dim-0 truncation** of a polygraph. A bare inductive datatype amnesias
dimensions ≥ 1: the rewrites, the rewrites-between-rewrites, the
coherences. The polygraph keeps them all. K11.10–K11.12 ship the
**bijection** `Term ⇌ PolyTerm` (75 ctors, both directions), which
*proves* the dim-0 truncation loses no term-level information. Hence:

> Everything done with trees = the dim-0 cells of a polygraph.
> Everything trees *cannot* cleanly express — rewriting as an algebra
> (not an external relation), confluence as 2-cells, coherence as
> 3-cells, concurrency as interchange (§2.7), separation as horizontal
> composition (§2.7), cost as cell weights (§8), grades as cell labels
> (§3) — the polygraph does **natively**. Trees see only dimension 0.

**"Everything is a cell."** Under the polygraph lens the kernel's notions
unify into one indexed structure:

    well-typed term       = dim-0 cell        (RawPolyTerm)
    reduction step        = dim-1 cell        (Step ⇌ Dim1Cell, K11.16)
    confluence proof      = dim-2 cell        (cd_lemma ⇌ Dim2Cell, K11.17)
    coherence             = dim-3 cell        (Squier/pentagon, K11.18/19)
    concurrent execution  = pasting diagram   (independent 1-cells, §2.7)
    cost                  = cell weight       (tropical, §8 / K11.19)
    grade / permission    = cell label / subdivision (§3, §2.6)

**Dual-primary architecture (the honest nuance).** "Polygraph superior
for everything" is right at the *reasoning* level but needs one
refinement at the *kernel-compute* level:

- **Tree = computational substrate.** Lean computes on inductives by
  `rfl`; FX's signature `Term.toRaw t = raw : rfl` definitional erasure
  depends on `RawTerm` being THE index. The bijection is a *function*,
  not a definitional identity — index `Term` by `PolyTerm` and
  `toRawTerm (toPoly t) = t` becomes a propositional theorem, losing the
  free erasure the whole kernel rests on. Structural recursion over the
  inductive is free; recursion over `PolyCell` needs well-founded
  recursion (K11.3 ships well-foundedness, but it is not structural).
- **Polygraph = reasoning substrate.** Rewriting, confluence,
  concurrency, cost, separation, grades — all expressed as cells.
- **Bijection = the bridge** (K11.10–12). Transport reasoning freely;
  you never lose a term.
- **HARD CONSTRAINT.** Do NOT swap `RawTerm`-as-index for
  `PolyTerm`-as-index in the kernel — that breaks `toRaw = rfl`. Keep the
  tree as index; lift to the polygraph to reason, descend via the
  bijection to compute. Slogan: **reason in the polygraph, compute in the
  tree, cross via the bijection.**

**Prop→Type caveat (recurring).** The bijection is a `Type` isomorphism,
so cell *structure* (composition, weights, labels, subdivisions)
transports freely. Cell *proofs* (`cd_lemma`, interchange-soundness) are
`Prop`-valued and do NOT come free across it — reuse the shipped
theorems, do not regenerate them. This is exactly why §8's "derive
confluence from cells" was refuted while §2.7's "concurrency *structure*
from cells" holds: structure is Type, soundness is Prop.

**What this reorganizes.** This is not a §8-local idea — it is the
organizing principle for the whole dossier. §7 (Allais traversals)
become **polygraph morphisms** composing by K11.4/5/6; §2.7
(concurrency / separation) is the cell algebra; §8 (confluence / cost)
is the higher cells; §3 (grades) are cell labels. The polygraph is the
unifying lens; the tree is the compute kernel; the bijection joins them.

**Apex of:** Burroni 1993 (computads/polygraphs) · Street (parity
complexes) · Ara–Burroni et al. 2023 · FX K11.10–12 bijection (the
shipped justification that the truncation is lossless).

## 9. Decidable conversion — polarization-directed NbE + two-tier equality  📋  (~2–3K LoC)


**Partial-fragment Conv** is `Delay Bool` (§2): semi-decidable, correct.

HIT needed to quotient by definitional equality — you need
normalization. The HIT framing for *this* quotient was solving a
non-problem.

**(d) Observational quotients via `oeq`** — Altenkirch–McBride OTT

## 16. Honest limits (the genuine "bullshit" boundary)

Three things are *not* zero-axiom achievable — and in each case that is
correct, not a compromise:

1. **Decidable Conv on the partial (guarded) fragment** — impossible by
   Turing. You get *semi-decidable* `Delay Bool`, which is the only
   sensible semantics once termination is surrendered. Not a loss.
2. **Lean-meta-level HITs** — blocked by Lean's UIP kernel. But
   object-level HITs via `Step` (§10b) deliver the full feature; you
   never needed meta-level.
3. **Choice/LEM-dependent classical theorems** (well-ordering,
   non-constructive existence) — genuinely independent of computational
   foundations; no reduction rule recovers them. A computational trust
   root *should* reject them. Here "zero-axiom or bullshit" is exactly
   right.

Every other cake is in the computational-axiom class: turn the axiom
into a `Step` rule (univalence, funext, HITs, quotients) or a guarded
coinduction (partiality), pay the honest cascade, and `#print axioms`
stays clean.
